## 4. 진행 중: 포토박스 트윈 Sim-to-Real

목적: 직접 원격조종한 정지 소켓 시범(`plug_static`) 69개의 관절 궤적을 Isaac 트윈의 SO-101에 그대로 넣고, 앞, 손목 카메라를 **시뮬레이션으로만** 렌더해 학습한다.
상태와 동작은 실물 값 그대로, 화면만 시뮬레이션. 그 모델을 실물에서 재면 "화면의 Sim-to-Real" 결과가 된다. MuJoCo는 쓰지 않는다.

| 단계 | 파일(~/plugbot, main 브랜치, 커밋 515f919) | 상태(21:20) |
|---|---|---|
| 1 내보내기 | `isaac/twin/export_episodes.py` → `data/twin_src/` | 끝(69개, 30,920장면) |
| 2 메시 | `isaac/twin/make_twin_meshes.py`(실제 출력 덮개 STL D27.5, 흰 소켓) → `isaac/twin/twin_meshes.npz` | 끝 |
| 3 렌더 | `isaac/twin/run_twin.py --render --rand` → `data/twin_render/`(로그 `data/twin_render.log`) | **도는 중**, 21:32쯤 끝 |
| 4 데이터셋 | `~/lerobot_env/bin/python isaac/twin/build_dataset.py` → `local/plug_twin` | 대기 |
| 5 학습 | `cd ~/plugbot && STEPS=20000 bash act/train.sh plug_twin full act_twin_v1` (약 1시간 반) | 대기 |
| 6 실물 측정 | `bash act/rollout.sh act_twin_v1 eval static`(그리고 흔들림). 판정은 녹화 화면 버튼, 집계 `tools/tally_rollouts.py` | 로봇 연결 필요 |
| 7 발표 반영 | 10장 가설에 한 줄 + 대본. 실패해도 숫자 그대로 | 대기 |

트윈 미리보기(실물과 비교): `~/plugbot/outputs/twin_preview_*.png`. 명령은 Isaac 파이썬에
`LD_LIBRARY_PATH=~/isaacsim_compat/lib OMNI_KIT_ACCEPT_EULA=YES`를 붙인다. 렌더를 멈출 때 `pkill -f run_twin`은 셸까지 죽이니 PID로 끈다.
트윈에서 맞춘 것: 보라색 팔과 검은 서보, 검은 종이 포토박스, 세운 판, L자 받침 둘, 바닥판 볼트(소켓 중심 12 cm 위), 앞 카메라(소켓 옆에서 팔 쪽), 손목 카메라(덮개 링 위).
남은 차이: 실물의 케이블, 판 질감, 흰 소켓의 모양 세부. 시간 남으면 도메인 무작위화 폭을 넓힌다.
