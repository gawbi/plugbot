4. 작업 전 `git pull`, 작업 뒤 `git add docs/business .claude/skills && git commit && git push` (다원님과 같은 브랜치, 폴더만 다르다)

- 지금 쓸 수 있는 스킬을 확인한다(조사, 스프레드시트, 문서, 차트 관련 스킬이 있으면 쓴다).

  2) jueun-public-data: 공공데이터 받기, 정리(출처, 기준일 기록), 발표용 그림 만들기(16:9에 들어가는 크기, 한글 폰트)

## 2. 팀 스토리 (내 근거가 받쳐 줄 줄기)
- 시작: 현대차그룹 로보틱스랩의 전기차 자동 충전 로봇(ACR). 땅 위에 멈춘 전기차는 이미 로봇이 충전한다(2024 팩토리얼 성수, 2025 인천공항 실증)
- 질문: 흔들리는 전기 선박은? 아직 사람이 무거운 케이블을 꽂는다
- 답: 육상의 꽂기를 해상으로(Land2Sea). 파도 예측 + 모방학습
- 내 몫: "이 문제가 얼마나 크고(시장, 규제), 누가 돈을 내고(고객, BM), 3~6개월 안에 무엇을 하는가(계획)"를 숫자로 받친다
- 차별점은 경쟁사 비교표 대신 '현대차 ACR 대비' 한 장으로 간다(멈춘 차 vs 움직이는 소켓). 경쟁사 표는 만들지 않는다.
  다만 질의응답 대비로 기존 선박 자동 연결 장치(Cavotec 등)가 무엇을 하고 무엇을 못 하는지는 qa_business.md에 짧게 정리해 둔다

## 3. 대회 규정 (2026-11-03 사전 오리엔테이션)
- 발표 필수 4가지 중 ④ **향후 3~6개월 사업화 계획**이 내 몫이다(빠지면 감점). 사업화 15점, 사용자 편의성과 실용성 15점
- 대회 핵심: 2개 이상 도메인 융합 + **AI와 데이터 활용**. 심사위원과 멘토에 해양 빅데이터와 AI 전문가(해양과학기술원, 해양수산개발원), 변리사, 사업화 컨설턴트가 있다
- 주최 측이 권한 공공데이터: 공공데이터포털(data.go.kr), 통계청 KOSIS, 기상청(data.kma.go.kr), 한전 데이터포털과 전력거래소(SMP),
  국립해양조사원 바다누리(khoi.go.kr), 해양수산부 PORT-MIS(항만별 선박 입출항)
- 선상 인터넷은 위성(하루 2.5 GB, 느림). **조사와 데이터 내려받기는 11/7까지 끝낸다**
- 선상 멘토링: 11/8, 11/9 밤 21:00~24:00(2일차는 원하는 멘토 회차에 신청, 회당 25분)
