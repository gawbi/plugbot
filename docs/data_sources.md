# 데이터 출처, 이용 조건, 활용 범위

PlugBot(팀 Land2Sea)이 쓴 데이터와 제3자 자료를 모두 적는다. 대회 안내(2026-11-07, "데이터의 출처, 제공기관, 이용 조건 및 활용 범위를 명확하게 기재")에 따른 문서다.
상태 표시: **확인** = 제공 페이지에서 조건을 읽음(날짜 적음), **확인 필요** = 아직 못 읽음. 못 읽은 것은 추정으로 채우지 않는다.
공공데이터의 상세 기록(파일, 기간, 가공)은 `docs/business/public_data.md`(pitch 브랜치, 주은)에 있다.

## 0. 확인 필요(주은, 11/8까지)
- 국립해양조사원 바다누리 실측 파랑 자료의 이용 조건: 소개 페이지에는 조건 문구가 없었다(11/7). 자료 받은 화면이나 저작권 정책 페이지에서 확인.
- 기상청 해양기상부이 자료에 공공누리 제1유형 표시가 붙어 있는지: 포털 정책에는 "자유이용 자료는 제1유형(출처표시)"라고 돼 있다(11/7). 받은 자료 페이지에서 표시 확인.
- Isaac Sim에 들어 있는 하늘 HDR(champagne_castle_1_4k)의 자산 라이선스 문구.
